# Зіставлення перед завершенням AUTO

Вихідна версія b749f9e, ТЗ v1.0 та уточнення користувача є основою цього проходу.
Працюючі 96 перевірок охоплюють картку, довідники, історію, МВО, ролі,
дублікати й повторне завантаження моделей. Їх потрібно зберегти.

| Прогалина | Послідовність закриття | Доказ завершення |
| --- | --- | --- |
| Документи, безпечні вкладення та версії | Крок 1 | Сервісні/UI тести, перевірка доступу й шляхів |
| Обладнання, зняття, версійні примітки | Крок 1 | Історія без фізичного видалення, права/конфлікти |
| Повне резервування й відновлення | Крок 1 | Відновлення копії SQLite разом з файлами та checksum |
| Норми, початкові/журнальні показники | Крок 2 | Дати, одиниці, джерела, підтвердження, незмінні знімки |
| Персональні фільтри, створення на основі | Крок 2 | Розділення користувачів і дозволений перелік полів |
| Excel експорт/імпорт/журнал | Крок 3 | Типи клітинок, мапінг, preview, дублікати, повторний імпорт |
| Три реальні файли | Крок 3 | Локальний звіт, формули/cache, тимчасова БД без автозлиття |
| Windows запуск та інструкції | Крок 4 | .cmd, backup/restore/update, локальна прив'язка |
| Повна таблиця AT-01–AT-38 | Крок 4 | Посилання на тести, чесні часткові/неперевірені сценарії |

Міграції виконуються спочатку на заповненій тестовій копії, потім на копії
поточної БД; перед робочим оновленням створюється перевірений backup.
Реальні Excel, БД, вкладення та докладні звіти з ідентифікаторами залишаються
поза Git. Реальний імпорт потребує явного підтвердження перегляду.
«ВИБУЛА» зіставляється з «Передано» без вигадування дати або одержувача.
