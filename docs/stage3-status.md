# Документи обладнання та примітки

Завершено третій етап на основі наявної архітектури. Міграція 0005 додає
документи, незмінні версії та метадані вкладень, обладнання, примітки і їх версії.
Файли зберігаються тільки в локальному data/attachments під випадковими іменами.
Права перевіряються також при читанні файлу; перевіряються належність картці,
шлях, тип/підпис, розмір і SHA256. Імена з traversal, макроси, підроблені типи
та небезпечні посилання відхиляються. Помилка документа скасовує SQLite-запис
та прибирає лише нові створені файли. Старі версії доступні для завантаження.

Обладнання має кількість, необов'язкові дати, зняття й фільтр. Примітки мають
автора/UTC час, нові зверху, версії, приховування без фізичного видалення.
Усі записи блокують видалення картки та мають аудит і захист версій.

Резервна копія містить SQLite, дерево вкладень і manifest SHA256.
Перевіряються integrity_check, foreign_key_check та наявність усіх вкладень БД.
Відновлення вимагає підтвердження, перевіряє копію до заміни, резервує поточний
стан, підтримує відкат файлових замін. Працюючий UI утримує OS-lock для
заборони відновлення під час роботи. Застосунок слід закрити перед restore.

Перевірки: tests/test_records.py (ролі, типи/шляхи/розміри, checksum, версії,
зняття, приховування, залежності та повне відновлення); наявні міграційні/UI/reload
тести. 53 пов'язані тести пройшли, додатковий UI-сценарій документів/примітки/
обладнання також пройшов. Ruff без помилок. Міграція спершу пройшла заповнені
тестові копії й копію локальної БД, потім локальну БД з перевіреним backup.
