# Транзакція погодженого імпорту

Імпортер використовує спільну фабрику сесій з `auto.transactions`.
Додавання довідників, побудову актуального перегляду та `apply_import` можна
об'єднати зовнішнім `atomic(engine)`. У разі винятку відкочуються картки,
початкова історія, довідники, аудит, журнал імпорту та квитанції рядків.

Звичайний імпорт зберігає обробку помилкових рядків із пропуском та звітом.
Для застосування повністю погодженої вибірки однією транзакцією потрібно
перевірити результати всередині `atomic`: якщо будь-який погоджений рядок
пропущено, підняти виняток до завершення зовнішнього контексту.

Перед застосуванням перевіряються актуальність джерел і робочої БД,
резервна копія SQLite з вкладеннями та погоджені виправлення. Приховані
підстановки дат, показників чи ідентифікаторів не допускаються.

Перевірки в `tests/test_import_diagnostics.py` відтворюють збій після створення
першої картки та успішне збереження вибірки. Перевіряються також квитанції,
історія, довідники, аудит і журнал. Реальні рішення, вихідні файли та звіти
зберігаються лише локально поза Git.
