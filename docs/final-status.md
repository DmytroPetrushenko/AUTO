# Передача локальної версії AUTO для Windows

Основа — чинний проєкт і ТЗ v1.0, звіти першого/другого етапів, уточнення про
вилучення помилкового типу та трактування «ВИБУЛА». Проєкт продовжено без
переписування; заповнені користувацькі дані в робочу БД не імпортовані.

## Відповідність і зміни

1. **Документи/вкладення, обладнання, примітки.** Міграція 0005, незмінні
   версії документів/файлів/приміток, зняття обладнання без видалення, аудит,
   права в сервісах, перевірки шляхів/контрольних сум/типу/розміру.
2. **Облік і реєстр.** Міграція 0006, датовані норми з реквізитами наказу,
   початкові/журнальні показники з джерелом і підтвердженням, приватні набори
   фільтрів, копіювання дозволених характеристик. «Немає показників» відмінне
   від нуля. −15% тільки в знімку конкретного застосованого документа.
3. **Excel.** Міграція 0007, точний експорт видимої вибірки, явний повний
   експорт, шаблон, довільний мапінг, окреме дослідження формул/кешу,
   ручне уточнення числових ID, перегляд, погодження дублікатів, явне
   підтвердження, звіт пропущених рядків, журнал та квитанції ідемпотентності.
   Наявні автомобілі не перезаписуються.
4. **Завершальні виправлення.** Спільна транзакція всіх змінених форм картки
   з попереднім переглядом, відкат SQLite/аудиту/нових файлів при пізній помилці;
   окремі кнопки залишені для одного запису. Редактори тримають відкриту версію
   й чернетки, виявляють конфлікт і не перезаписують чужі зміни.
   Виправлено закриття sqlite3-з'єднань, яке блокувало заміну файлу Windows;
   перевірено відновлення поверх наявної БД та відкат файлових замін.
5. **Передача.** install/start/update/backup/restore.cmd, CLI перевірки схеми,
   цілісності та backup-manifest, інструкція в [README](../README.md).

Основна схема `vehicles` та її UUID/датовані записи залишені. Нові дані —
окремі таблиці з FK до автомобіля; файли — `attachments`, метадані — SQLite.
Перехід 0004→0005 додає записи документів/обладнання/приміток;
0005→0006 — норми/показники/фільтри; 0006→0007 — журнал імпорту/квитанції.
Застарілі записи не переносяться з домисленими датами. `drop_all` не використовується.

## Реальні джерела

Перевірено всі три надані XLSX. У реєстрі 42 заповнені рядки; у **тимчасовій**
БД створено 27 кандидатів, 15 рядків пропущено. Це не оцінка кількості
підтверджених унікальних автомобілів. Є 18 груп візуально схожих номерів,
83 833 формули, 1 676 формул без кешу. Генератори виключені, координати не
перенесені. Норми/показники з календарних паливних блоків не імпортовані без
ідентифікації автомобілів, дат і реквізитів наказів. «ВИБУЛА» → «Передано»,
дата та одержувач лишаються невідомими.

Докладні локальні матеріали: `.local/real-trial-20261020T122111/`.
У Git лише знеособлений [звіт і мапінг](excel-status.md). Справжній імпорт
вимагає перегляду кандидатів/проблемних рядків, потрібних довідників та явного
підтвердження нового перегляду користувачем у UI. Робоча БД на момент передачі
залишається без автомобілів із цих файлів.

## Приймання та межі перевірки

[Матриця AT-01–AT-38](acceptance.md): **36 виконано, 2 частково**.
AT-13 та AT-34 перевірені як інтеграційний контракт незмінного застосованого
документа; наскрізний справжній дорожній лист неможливий без відкладеного модуля.

Автотести охоплюють створення/редагування/скасування, дублі, ролі/файли,
датовані межі, майбутні події, конфлікти версій/перегляду, агрегатну транзакцію,
норми/знімки/показники, Excel, сесійну перезагрузку моделей, міграції заповнених
копій та backup/restore Windows. Ручні M-01/M-02 — браузер на синтетичній БД.
Остаточний прогін на цьому Windows / Python 3.12.10: **155 тестів пройшли**,
у тому числі 31 сценарій у `tests/test_ui.py`; пропущених тестів немає.
Ruff, перевірка форматування та `pip check` пройшли; робоча SQLite `0007`
пройшла CLI check (схема, integrity_check, foreign_key_check).
`start.cmd` запущений на цьому ПК; локальний `/health` повернув HTTP 200,
реєстр відкривається за `http://127.0.0.1:8501/`. Робочих автомобілів — 0.

Не перевірено/не реалізовано: гарантований browser-beforeunload, відмова
живлення в середині файлової заміни, усі версії Office/антивірус, чистий інший
ПК, мережевий режим, повний журнал/ПММ/дорожні листи, склад, автогенерація.
Це не позитивні результати тестів. Інтерфейси майбутніх модулів —
[integrations.md](integrations.md). Місцеві ролі налаштовуються довіреним
процесом Windows; парольна мережева авторизація не додавалася.

До кожної зміни робочої схеми створено перевірений bundle SQLite+вкладення;
спочатку міграції проганялися на заповнених тестових копіях і копії робочої БД.
Шляхи та SHA256 приватних копій не публікуються. Нову інсталяцію слід перевіряти
через `auto.cli check`, а власний backup — через `verify-backup`.
