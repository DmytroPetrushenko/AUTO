# Межі та контракти інтеграцій

Інші журнали використовують незмінний UUID `vehicle_id`, а не військовий номер.
Timestamp аудиту — UTC, дата фактичної події — календарна; сьогодні — Europe/Kyiv.

`auto.accounting.add_reading(engine, vehicle_id, data, actor, kind="journal",
external_id=...)` приймає value, unit (`км`/`мотогодини`), measured_on, source,
confirmed. Стабільний унікальний external_id захищає від повторів. Майбутні
дати, від'ємні/нескінченні числа й інша одиниця відхиляються. Старі показники
не перераховуються. `current_reading(engine, vehicle_id, day=None)` повертає
останній релевантний рядок або None. UI вводить лише початковий показник;
повний журнал, його підтвердження й підключення джерела — майбутній модуль.

`auto.history.register_document_lock(engine, vehicle_id, document_reference,
document_date, actor, adjustment_percent=-15)` зберігає стан на дату з
реквізитами МВО, нормою, коригуванням і показником. Знімок захищений від змін
SQLite-тригером. Коригування належить документу, не vehicles.
Історичні зміни й зміни норм перевіряють знімки та блокують конфлікт з конкретним
посиланням. Перерахунку/перепроведення немає. Не видаляйте блокування вручну:
узгоджене сторнування й політику випуску неексплуатованої техніки має реалізувати
майбутній модуль. Наскрізна робота справжнього дорожнього листа не перевірена.

Actor передається довіреним локальним процесом. Сервісні права не замінюють
прав Windows на SQLite/файли. Мережевих API, SSO та обмеження видимості за
підрозділом у цій версії немає.
